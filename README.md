# Subterra · D-5 Final package

Lars Chokier · Cross Media Design I · Erasmushogeschool Brussel
Festival: **Subterra** · *Zero bars. All bass.*

A weekend festival inside the Caves of Han that gets city students into nature. This repository holds every file of the final package. The videos are on Canvas (see the list at the bottom).

## 1_Touchpoint · the core touchpoint

| File | What it is | Channel | Spec |
|---|---|---|---|
| `prototype_link.md` | Links to the interactive map: the Figma prototype and the published Figma site | Map website (core touchpoint) | Mobile, opens in any browser |
| `Mobile.png` – `Mobile_9.png` | The 9 screens of the key moment, in order | Map website | PNG, 430 × 1080 px |

**How to run it:** open the published link in `prototype_link.md` on a phone or in a browser, and tap through from the first screen. No install needed.
